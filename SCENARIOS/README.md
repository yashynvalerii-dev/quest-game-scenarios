# Public scenario templates

Store spoiler-free descriptions, replayable mechanics and approved examples here.

Each scenario should include:
- scenario ID, title, owner decision status, version;
- player goal, setting and intended experience;
- object/zone reference list and coordinate assumptions;
- trigger → conditions → actions graph;
- failure, cancellation, replay, multiplayer and offline cases;
- Node-RED mapping, test cases and dependencies;
- privacy/spoiler classification.

Confidential story details go ONLY into the private repository.
